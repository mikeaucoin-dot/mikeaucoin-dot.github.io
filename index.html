Zedwork Private Backup Verification

A private desktop tool for household organization and checking personal backups.

This is an information website. The application runs on its owner's private computers. This site has no sign-in, school records, calendar contents or backup files.

What the Google connection does

  • Reads selected or linked Google Drive documents and metadata needed for the owner's document and backup workflows.
  • Reads the owner's selected calendar lists and events for a combined household view.
  • Creates and updates application-managed dates and preparation reminders in a calendar chosen by the owner.

The owner chooses the Google account and permissions at Google's authorization screen. Existing calendar events outside the application's management are preserved.

Private processing

The local application stores its working records, document versions and history on the owner's computer. Scheduled collection, document extraction and reminders run with ordinary local software. The Google API connection does not require a paid AI service.

When the owner configures separate Google Drive for desktop backup copying, Google Drive for desktop handles that upload. This information site does not receive those backups.
